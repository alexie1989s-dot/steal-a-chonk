# Glossy UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every piece of the game's own UI the glossy look the user asked for (2026-10-04): round, glass-like bubble buttons that feel good to press, glass panels for the HUD, toasts, prompts and reveal card, and a glassy highlight on world name plates.

**Architecture:** One client kit, `src/client/Ui.luau`, gains the building blocks: a colour sheen, a wet-look gloss cap, a thin inner rim, a sweeping glint, a glossy bubble, a glass panel and a rebuilt pressable button. Every UI module then builds its frames from these helpers instead of its own corner-and-stroke code. The server's world-label plate (`Models.luau`) gets the same highlight. It is cosmetic and client-side only: no remotes, no server rules, no gameplay numbers change.

**Tech Stack:** Luau, Roblox GUI instances (UIGradient, UIStroke, UICorner, CanvasGroup, BillboardGui), Rojo 7.7, Lune 0.10 tests, StyLua, Selene, Studio MCP and the window-capture tools.

**Spec:** `docs/superpowers/specs/2026-09-06-steal-a-chonk-design.md` (§19 UI and UX principles). User request of 2026-10-04: "buttons should look glossy and glass type round … beautiful to press, polish everything to max level".

**Part of a three-plan polish pass:**
1. **This plan: glossy UI.**
2. **Next: the bigger map.** It becomes larger and uneven: Terrain with gentle slopes (§6: "gentle slopes, wide lanes"), an irregular outline instead of a circle, and nests and guardians that follow the ground. The lighting is upgraded in the same plan.
3. **After that: VFX and ambient life.** This covers burrito auras and loot pillars, grab, BONK, hatch and curb bursts, dust and trails, fountain water and ambient motes. It ends with a phone performance pass.

Plans 2 and 3 are written when this one is done, against the code as it then stands.

## Global Constraints

- **Assets:** engine built-ins only. No image asset ids. Bundled fonts only: Luckiest Guy (capitals only), Fredoka One (mixed case) and Gotham. This is the user ruling of 2026-10-04 in `codex/PROJECT_CONTEXT.md`.
- **Spec §19:** "Mobile-first. Big one-thumb buttons in the lower corners." "One consistent rounded visual language." "No unnecessary animation." The glint is therefore slow (one sweep every 4.5 s or more), never in step across a row, and never on world labels.
- **Phone fit:** the HUD bar and the toast stack shrink to a `UIScale` of 0.62 on phones. Every decoration must still look whole at that scale.
- **Cosmetic only:** UI changes are cosmetic. The server stays authoritative, and prompts keep the engine's input and the server's hold timing.
- **Chonk models are untouched:** art is paused (`AGENTS.md`).
- **Commits and pushes:** commit and push only when the user asks. Never add a `Co-Authored-By` trailer. Before any commit, scan for usernames, machine paths, emails and tokens. `README.md` and `codex/HANDOFF.md` change in the same push.

## Review Focus

1. **Phone scale.** At the HUD's smallest `UIScale` (0.62), the inner rim, the gloss cap and the button lip must stay inside their shapes and look like one object. Checked in Task 2 by forcing the scale.
2. **White text on a white highlight.** The gloss cap sits behind white labels such as BAT, STEAL and PEDAL!. The label must stay readable over it at the glossiest point. Checked in Tasks 1 and 3 by capture.
3. **Toast fade.** A toast fades as one `CanvasGroup`. The new rim, gloss and bubble must fade with it, and the tone-coloured edge must still show. Checked in Task 2.
4. **Glint leak.** Prompts are built and destroyed every time one shows. Glints of destroyed GUIs must leave the update list, or it grows without bound. Checked in Task 3 with `Ui.glintCount()` after 20 show and hide cycles.
5. **Touch press.** On a phone the Bat button gets a touch, not a mouse. `MouseButton1Down` and `MouseButton1Up` fire for touch on a `GuiButton`, so the press sink must play and release. Checked in Task 1 with an MCP click on a test button, which goes through the same `GuiButton` path.

- [ ] **Step 1: Write `burst.ps1`.** It captures the viewport repeatedly and names each frame by its Unix-millisecond capture time, so a frame can be matched to a camera script's timestamps. The crop default is for a 2576×1408 Studio window.

```powershell
param([string]$Dir, [int]$Seconds = 30, [int]$Every = 400, [string]$Crop = "11,175,2154,1328")
# Captures the Studio game viewport repeatedly; each frame is named by its Unix-ms capture time.
# $Crop is "x0,y0,x1,y1" in window pixels (the inside of Studio's blue viewport border).
Add-Type -AssemblyName System.Drawing
if (-not ("SnapB" -as [type])) {
Add-Type @'
using System; using System.Runtime.InteropServices;
public class SnapB {
  [DllImport("user32.dll")] public static extern bool PrintWindow(IntPtr h, IntPtr hdc, uint flags);
  [DllImport("user32.dll")] public static extern bool GetWindowRect(IntPtr h, out RECT r);
  [StructLayout(LayoutKind.Sequential)] public struct RECT { public int L, T, R, B; }
}
'@
}
New-Item -ItemType Directory -Force $Dir | Out-Null
$p = Get-Process RobloxStudioBeta | Where-Object { $_.MainWindowTitle -like "*Roblox Studio*" } | Select-Object -First 1
$hwnd = $p.MainWindowHandle
$r = New-Object SnapB+RECT
[SnapB]::GetWindowRect($hwnd, [ref]$r) | Out-Null
$w = $r.R - $r.L; $h = $r.B - $r.T
# Not $crop: PowerShell variables ignore case, so that would be the [string] parameter above.
$c = $Crop.Split(",") | ForEach-Object { [int]$_ }
$rect = [System.Drawing.Rectangle]::new([int]$c[0], [int]$c[1], [int]($c[2] - $c[0]), [int]($c[3] - $c[1]))
$end = (Get-Date).AddSeconds($Seconds)
$n = 0
while ((Get-Date) -lt $end) {
  $t0 = Get-Date
  $ms = [DateTimeOffset]::UtcNow.ToUnixTimeMilliseconds()
  $full = New-Object System.Drawing.Bitmap $w, $h
  $g = [System.Drawing.Graphics]::FromImage($full)
  $hdc = $g.GetHdc()
  [SnapB]::PrintWindow($hwnd, $hdc, 2) | Out-Null
  $g.ReleaseHdc($hdc); $g.Dispose()
  $part = $full.Clone($rect, $full.PixelFormat)
  $part.Save((Join-Path $Dir "$ms.png"), [System.Drawing.Imaging.ImageFormat]::Png)
  $part.Dispose(); $full.Dispose()
  $n++
  $left = $Every - ((Get-Date) - $t0).TotalMilliseconds
  if ($left -gt 0) { Start-Sleep -Milliseconds $left }
}
"frames=$n"
```

- [ ] **Step 2: Write `pick.py`.** It copies the frame nearest a point inside each shot's hold window and writes a 1100-px JPEG preview for reading.

```python
"""pick.py <burst dir> <out dir> name=startms:holdms[:frac] ... -> nearest frame per shot + preview."""
import os, sys, shutil
from PIL import Image
src, out = sys.argv[1], sys.argv[2]
os.makedirs(out, exist_ok=True)
frames = sorted(int(f[:-4]) for f in os.listdir(src) if f.endswith(".png"))
for spec in sys.argv[3:]:
    name, rest = spec.split("=")
    parts = rest.split(":")
    start, hold = int(parts[0]), int(parts[1])
    frac = float(parts[2]) if len(parts) > 2 else 0.75
    want = start + hold * frac
    inside = [f for f in frames if start + 700 <= f <= start + hold - 150]
    pool = inside or frames
    best = min(pool, key=lambda f: abs(f - want))
    shutil.copy(os.path.join(src, f"{best}.png"), os.path.join(out, f"{name}.png"))
    im = Image.open(os.path.join(out, f"{name}.png")).convert("RGB")
    im.thumbnail((1100, 1100))
    im.save(os.path.join(out, f"{name}_prev.jpg"), quality=85)
    print(name, best, "offset", best - start, "of", hold, "inside" if inside else "NO FRAME INSIDE")
```

- [ ] **Step 1: Replace `src/client/Ui.luau` with the kit.**

```lua
-- Shared look for the client's own UI: glossy bubble buttons and glass panels, the style most
-- Roblox games give the things you press. Built from plain GUI instances (gradients, strokes,
-- corners) and the engine's bundled fonts, so it needs no image assets.
--
-- Layering: each helper puts its decoration at a ZIndex relative to the shape it decorates, and
-- every ScreenGui and BillboardGui that uses them runs in Sibling mode, where a child always draws
-- over its parent and siblings stack by ZIndex.
local RunService = game:GetService("RunService")
local TweenService = game:GetService("TweenService")

local Sfx = require(script.Parent.Sfx)

local Ui = {}

Ui.INK = Color3.fromRGB(18, 15, 28)
Ui.PANEL = Color3.fromRGB(34, 30, 46)

local WHITE = Color3.new(1, 1, 1)
local BLACK = Color3.new(0, 0, 0)
-- How long one glint takes to cross a shape, in seconds.
local SWEEP = 0.65
-- A narrow bright band in the middle of an otherwise clear gradient.
local STREAK = NumberSequence.new({
	NumberSequenceKeypoint.new(0, 1),
	NumberSequenceKeypoint.new(0.42, 1),
	NumberSequenceKeypoint.new(0.5, 0.5),
	NumberSequenceKeypoint.new(0.58, 1),
	NumberSequenceKeypoint.new(1, 1),
})

-- Towards white (f > 0) or black (f < 0) by that fraction.
function Ui.shade(color: Color3, f: number): Color3
	return if f >= 0 then color:Lerp(WHITE, f) else color:Lerp(BLACK, -f)
end

function Ui.corner(parent: Instance, radius: UDim): UICorner
	local c = Instance.new("UICorner")
	c.CornerRadius = radius
	c.Parent = parent
	return c
end

function Ui.stroke(parent: Instance, color: Color3, thickness: number, transparency: number?): UIStroke
	local s = Instance.new("UIStroke")
	s.Color = color
	s.Thickness = thickness
	s.Transparency = transparency or 0
	s.ApplyStrokeMode = Enum.ApplyStrokeMode.Border
	s.Parent = parent
	return s
end

local function sheenColors(color: Color3): ColorSequence
	return ColorSequence.new({
		ColorSequenceKeypoint.new(0, Ui.shade(color, 0.3)),
		ColorSequenceKeypoint.new(0.5, color),
		ColorSequenceKeypoint.new(1, Ui.shade(color, -0.2)),
	})
end

-- The body colour of a glossy shape: lighter at the top, the colour itself through the middle and
-- deeper at the bottom. A UIGradient multiplies the background, so the background turns white and
-- the gradient carries the colour.
function Ui.sheen(shape: GuiObject, color: Color3): UIGradient
	shape.BackgroundColor3 = WHITE
	local g = Instance.new("UIGradient")
	g.Name = "Sheen"
	g.Rotation = 90
	g.Color = sheenColors(color)
	g.Parent = shape
	return g
end

-- Recolours a shape that was given a sheen (a tier band, a tone chip).
function Ui.recolor(shape: GuiObject, color: Color3)
	local g = shape:FindFirstChild("Sheen")
	if g and g:IsA("UIGradient") then
		g.Color = sheenColors(color)
	else
		shape.BackgroundColor3 = color
	end
end

-- The wet highlight across the top of a rounded shape: a white cap, inset and rounded like the
-- shape, that fades out downwards, so it reads as light on a curved surface.
function Ui.gloss(shape: GuiObject, radius: UDim, strength: number?): Frame
	local cap = Instance.new("Frame")
	cap.Name = "Gloss"
	cap.AnchorPoint = Vector2.new(0.5, 0)
	cap.Position = UDim2.fromScale(0.5, 0.07)
	cap.Size = UDim2.fromScale(0.86, 0.45)
	cap.BackgroundColor3 = WHITE
	cap.BorderSizePixel = 0
	cap.ZIndex = shape.ZIndex + 1
	cap.Parent = shape
	Ui.corner(cap, radius)
	local fade = Instance.new("UIGradient")
	fade.Rotation = 90
	fade.Transparency = NumberSequence.new(1 - (strength or 0.55), 1)
	fade.Parent = cap
	return cap
end

-- A thin light line just inside the edge: the detail that makes a shape read as glass.
function Ui.rim(shape: GuiObject, radius: UDim, transparency: number?): Frame
	local ring = Instance.new("Frame")
	ring.Name = "Rim"
	ring.AnchorPoint = Vector2.new(0.5, 0.5)
	ring.Position = UDim2.fromScale(0.5, 0.5)
	ring.Size = UDim2.new(1, -6, 1, -6)
	ring.BackgroundTransparency = 1
	ring.ZIndex = shape.ZIndex + 1
	ring.Parent = shape
	Ui.corner(ring, radius)
	Ui.stroke(ring, WHITE, 1.5, transparency or 0.6)
	return ring
end

type Glint = { gradient: UIGradient, period: number, start: number }
local glints: { Glint } = {}

-- A bright diagonal streak that sweeps across a shape every `period` seconds. It is a full-size
-- copy of the shape's outline, so the shape's rounded corners clip it.
function Ui.glint(shape: GuiObject, radius: UDim, period: number?): Frame
	local streak = Instance.new("Frame")
	streak.Name = "Glint"
	streak.Size = UDim2.fromScale(1, 1)
	streak.BackgroundColor3 = WHITE
	streak.BorderSizePixel = 0
	streak.ZIndex = shape.ZIndex + 2
	streak.Parent = shape
	Ui.corner(streak, radius)
	local g = Instance.new("UIGradient")
	g.Rotation = 24
	g.Transparency = STREAK
	g.Offset = Vector2.new(-1, 0)
	g.Parent = streak
	local every = period or 5
	-- Staggered, so a row of buttons never flashes in step.
	table.insert(glints, { gradient = g, period = every, start = os.clock() - math.random() * every })
	return streak
end

-- Sweeps a glint across now, on top of its own rhythm (a reveal card arriving).
function Ui.sweep(streak: Frame)
	local g = streak:FindFirstChildOfClass("UIGradient")
	for _, glint in glints do
		if glint.gradient == g then
			glint.start = os.clock()
		end
	end
end

-- How many glints are being driven, for the leak check in Studio.
function Ui.glintCount(): number
	return #glints
end

RunService.RenderStepped:Connect(function()
	local now = os.clock()
	for i = #glints, 1, -1 do
		local glint = glints[i]
		local g = glint.gradient
		-- Destroying a gui sets every descendant's Parent to nil: that glint is finished.
		if g.Parent == nil then
			table.remove(glints, i)
			continue
		end
		local t = (now - glint.start) % glint.period
		g.Offset = Vector2.new(if t < SWEEP then -1 + 2 * t / SWEEP else -1, 0)
	end
end)

-- A glossy round chip for an icon or a key. The caller sets its size, position and anchor.
function Ui.bubble(parent: Instance, color: Color3, zIndex: number): Frame
	local chip = Instance.new("Frame")
	chip.Name = "Bubble"
	chip.BorderSizePixel = 0
	chip.ZIndex = zIndex
	chip.Parent = parent
	local round = UDim.new(0.5, 0)
	Ui.corner(chip, round)
	Ui.stroke(chip, Ui.INK, 2)
	Ui.sheen(chip, color)
	Ui.gloss(chip, round, 0.7)
	return chip
end

-- A glass panel: dark and a little see-through, a faint reflection over its top half and a thin
-- bright rim inside an outline. `edge` colours the outline (a toast's tone); ink by default.
function Ui.glass(frame: GuiObject, radius: UDim, edge: Color3?)
	frame.BorderSizePixel = 0
	frame.BackgroundTransparency = 0.12
	Ui.corner(frame, radius)
	Ui.stroke(frame, edge or Ui.INK, if edge then 3 else 2.5)
	local g = Instance.new("UIGradient")
	g.Name = "Sheen"
	g.Rotation = 90
	g.Color = ColorSequence.new(Ui.shade(Ui.PANEL, 0.2), Ui.shade(Ui.PANEL, -0.25))
	g.Parent = frame
	frame.BackgroundColor3 = WHITE
	Ui.rim(frame, radius, 0.78)
	Ui.gloss(frame, radius, 0.14)
end

-- Heavy display type in white with an ink outline and a faint cool tint towards the bottom, the
-- genre's lettering.
function Ui.label(parent: Instance, text: string, font: Enum.Font?): TextLabel
	local label = Instance.new("TextLabel")
	label.Name = "Label"
	label.BackgroundTransparency = 1
	label.Size = UDim2.fromScale(1, 1)
	label.Font = font or Enum.Font.LuckiestGuy
	label.Text = text
	label.TextScaled = true
	label.TextColor3 = WHITE
	label.ZIndex = (if parent:IsA("GuiObject") then parent.ZIndex else 1) + 4
	label.Parent = parent
	local outline = Instance.new("UIStroke")
	outline.Color = Ui.INK
	outline.Thickness = 2.5
	outline.Parent = label
	local tint = Instance.new("UIGradient")
	tint.Rotation = 90
	tint.Color = ColorSequence.new(WHITE, Color3.fromRGB(222, 230, 255))
	tint.Parent = label
	local pad = Instance.new("UIPadding")
	pad.PaddingTop = UDim.new(0.18, 0)
	pad.PaddingBottom = UDim.new(0.14, 0)
	pad.PaddingLeft = UDim.new(0.12, 0)
	pad.PaddingRight = UDim.new(0.12, 0)
	pad.Parent = label
	return label
end

export type ButtonSpec = {
	name: string,
	size: UDim2,
	position: UDim2,
	anchor: Vector2?,
	color: Color3,
	text: string,
	round: boolean?,
	parent: Instance,
}

-- A glossy bubble button: a coloured face with a wet highlight, a bright inner rim and a glint,
-- sitting on a deeper "lip" of its own colour like the side of a sweet. Pressing sinks the face
-- onto the lip with a white flash; releasing springs it back. Returns the clickable face and its
-- label. The click sound plays on every press; connect `Activated` for the action.
function Ui.button(spec: ButtonSpec): (TextButton, TextLabel)
	local holder = Instance.new("Frame")
	holder.Name = spec.name
	holder.Size = spec.size
	holder.Position = spec.position
	holder.AnchorPoint = spec.anchor or Vector2.zero
	holder.BackgroundTransparency = 1
	holder.Parent = spec.parent
	if spec.round then
		local aspect = Instance.new("UIAspectRatioConstraint")
		aspect.Parent = holder
	end
	local scale = Instance.new("UIScale")
	scale.Parent = holder
	local radius = if spec.round then UDim.new(0.5, 0) else UDim.new(0.32, 0)
	local depth = if spec.round then 5 else 4

	local shadow = Instance.new("Frame")
	shadow.Name = "Shadow"
	shadow.AnchorPoint = Vector2.new(0.5, 0)
	shadow.Position = UDim2.new(0.5, 0, 0, depth + 3)
	shadow.Size = UDim2.fromScale(1, 1)
	shadow.BackgroundColor3 = Ui.INK
	shadow.BackgroundTransparency = 0.62
	shadow.BorderSizePixel = 0
	shadow.ZIndex = 1
	shadow.Parent = holder
	Ui.corner(shadow, radius)

	local lip = Instance.new("Frame")
	lip.Name = "Lip"
	lip.Position = UDim2.fromOffset(0, depth)
	lip.Size = UDim2.fromScale(1, 1)
	lip.BackgroundColor3 = Ui.shade(spec.color, -0.42)
	lip.BorderSizePixel = 0
	lip.ZIndex = 2
	lip.Parent = holder
	Ui.corner(lip, radius)
	Ui.stroke(lip, Ui.INK, 3)

	local face = Instance.new("TextButton")
	face.Name = "Face"
	face.Size = UDim2.fromScale(1, 1)
	face.BorderSizePixel = 0
	face.AutoButtonColor = false
	face.Text = ""
	face.ZIndex = 3
	face.Parent = holder
	Ui.corner(face, radius)
	Ui.stroke(face, Ui.INK, 3)
	Ui.sheen(face, spec.color)
	Ui.rim(face, radius, 0.5)
	Ui.gloss(face, radius, 0.62)
	Ui.glint(face, radius)
	local label = Ui.label(face, string.upper(spec.text))

	local flash = Instance.new("Frame")
	flash.Name = "Flash"
	flash.Size = UDim2.fromScale(1, 1)
	flash.BackgroundColor3 = WHITE
	flash.BackgroundTransparency = 1
	flash.BorderSizePixel = 0
	flash.ZIndex = face.ZIndex + 5
	flash.Parent = face
	Ui.corner(flash, radius)

	local up = UDim2.fromOffset(0, 0)
	local down = UDim2.fromOffset(0, depth - 1)
	local held = false
	local function spring(position: UDim2, size: number, time: number)
		local info = TweenInfo.new(time, Enum.EasingStyle.Back, Enum.EasingDirection.Out)
		TweenService:Create(face, info, { Position = position }):Play()
		TweenService:Create(scale, info, { Scale = size }):Play()
	end
	face.MouseEnter:Connect(function()
		if not held then
			spring(up, 1.05, 0.15)
		end
	end)
	face.MouseLeave:Connect(function()
		held = false
		spring(up, 1, 0.15)
	end)
	face.MouseButton1Down:Connect(function()
		held = true
		local info = TweenInfo.new(0.06, Enum.EasingStyle.Quad, Enum.EasingDirection.Out)
		TweenService:Create(face, info, { Position = down }):Play()
		TweenService:Create(scale, info, { Scale = 0.95 }):Play()
		flash.BackgroundTransparency = 0.6
		TweenService:Create(flash, TweenInfo.new(0.3), { BackgroundTransparency = 1 }):Play()
	end)
	face.MouseButton1Up:Connect(function()
		held = false
		spring(up, 1, 0.22)
	end)
	face.Activated:Connect(function()
		Sfx.play("click")
	end)
	return face, label
end

return Ui
```
